# BIGFOOT catalog gallery

Numbered images define the complete gallery, in order; `screenshots.json`
contains the published captions. These media files stay outside `assets/` and
do not enlarge the extension bundle.

- `1-hunt-preview.png`: `dist/bigfoot-scene-preview.json`, `spotted-desktop` fixture, rendered with `scenePreviewSvg` at 2×.
- `2-narrow-preview.png`: `dist/bigfoot-scene-preview.json`, `spotted-narrow` fixture, rendered with `scenePreviewSvg` at 2×.

See [catalog screenshot provenance and publishing](../../../../docs/CATALOG-SCREENSHOTS.md)
for capture versions, preview limitations, validation, and the screenshot-only
publishing command.
