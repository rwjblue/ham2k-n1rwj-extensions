Send contacts from HaLo to ARRL’s Logbook of the World (LoTW). This
temporary preview requires HaLo on desktop or mobile with extension API 29
and support for certificate files in account settings.

Enable **EXP PUSH**, then open **Settings → Exports & Imports → Services →
Logbook of the World**. Choose the `.p12` file you exported from TQSL.
The file contains your certificate and private key and stays on your device.
Use **Test**, then **Save**. Use **Exports → Push to Services** to send
unsent contacts for that callsign.
[ARRL’s certificate export guide](https://lotw.arrl.org/lotw-help/save-certificate/)

For processing results, open **Your Account → Your Activity → Result** in
LoTW. [ARRL’s processing results guide](https://lotw.arrl.org/lotw-help/view-accepted-qsos/)
