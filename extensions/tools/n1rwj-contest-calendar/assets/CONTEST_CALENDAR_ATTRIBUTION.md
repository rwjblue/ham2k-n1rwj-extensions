# Contest calendar data

Calendar data is provided by **ContestClock**, by Joe Leone, W4GGJ:

- Calendar and API: https://contestclock.com/
- Data documentation: https://contestclock.com/data
- Catalog source: https://github.com/w4ggj/contest-calendar
- Catalog license: Creative Commons Attribution 4.0 International
  (https://creativecommons.org/licenses/by/4.0/).

This extension normalizes the downloaded records, filters them for the selected
display, and formats their times. It preserves separate operating sessions and
links to sponsors' rules. It does not copy sponsors' rules text. Sponsor rules
remain the authoritative source; catalog coverage and verification can vary.

The extension's source is licensed under MPL-2.0. That license does not replace
the catalog's CC BY 4.0 license or sponsors' rights in their own rules.

No WA7BNM calendar content is downloaded or redistributed by this extension.
