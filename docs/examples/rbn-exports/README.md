# Generated RBN export examples

These are synthetic observations and contacts, generated by the production export hook with deterministic provider responses. They are not a record of N1RWJ's actual activation. Rebuild with `mise run rbn:export-samples`.

- [Complete report](complete/reception.html): history retrieval recovers the full fixture interval, including spots missed by visible polling.
- [Partial report](partial/reception.html): only early collected observations survive; a failed history request leaves later intervals unknown.

Each folder contains HTML, Markdown, individual-observation CSV, collected-evidence JSON, SVG map, and contact-context CSV exports. Unknown receiver location and missing SNR remain in the evidence. DEMO calls identify fictional contacts.
