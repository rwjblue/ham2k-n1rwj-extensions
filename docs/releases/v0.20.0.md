# v0.20.0 — Live RBN spots and catalog guides

RBN now uses Ham2K’s shared DX cluster connection to bring live skimmer
reports into **Spots** and **My Signal**. Every extension has new or
updated About text in the catalog and on compatible install screens.

## n1rwj-bigfoot

- Adds an About guide to the 2026 hunt, the forest panel, and the
  worksheet for reviewing contacts before applying for the certificate.

## n1rwj-bkg

  and which contacts count for **Worked the Gang**.

## n1rwj-contest-calendar

- Adds an About guide to adding the Home panel, finding upcoming events,
  and using the downloaded calendar offline.

## n1rwj-cwt

## n1rwj-ns

## n1rwj-randomgram

## n1rwj-rbn

- Live updates from Ham2K’s shared DX cluster are on by default. **Spots**
  starts with a Vail ReRBN snapshot and returns to Vail when the cluster
  disconnects or stops sending reports. **My Signal** combines live
  reports with recent Vail results. On the web, RBN uses Vail.
- This update requires Ham2K extension API 21, available in Ham2K Next
  26.11.0 build 193. Hosts on API 12–20 can install RBN 0.19.0 from the
  catalog. [Ham2K Next downloads](https://updates.ham2k.net/halo-next/latest.json)
- RBN asks for DX cluster command permission. On supported nodes, setup
  can reset saved spot filters for your cluster login, including filters
  used by other clients with that login. For Vail alone, turn off **Live
  updates from DX cluster** in **Settings → Spotting → RBN**.
- For each station, band, and mode, **Spots** shows the closest qualifying
  skimmer. The newest report wins when distances tie or none are known.
  Rows show signal-to-noise ratio and receiver distance when available.
- Newly delivered CW spots with a DXSpider Qualitee `Q:` marker can be up
  to five UTC minutes old. RBN retains the skimmer’s original report time.
- Updates About with live feed setup, receiver filters, and how to save
  reception evidence for an activation report.
