# v0.19.0 — CWT spot markers and HaLo compatibility

RBN supplies reception reports to the native Spots page without the old
contest and roster selector. In a CWT operation, spots with cached CWT
exchange details can show a badge. Select the spot to see the exchange
in call info.

## Shared changes

- Builds use Ham2K extension SDK 1.23.1 and tools 1.23.0. Each extension
  keeps its current minimum HaLo API.

## n1rwj-bigfoot

No extension-specific changes for BIGFOOT Hunt.

## n1rwj-bkg

- Adds an operator guide to the catalog and compatible install screens.

## n1rwj-contest-calendar

No extension-specific changes for N1RWJ Contest Calendar.

## n1rwj-cwt

- Marks eligible CW spots with a cached CWT exchange in CWT operations.
  The badge appears on rows with a source label, including RBN.
- Selecting a spot shows the available name and exchange in call info.
  Existing notes and operator corrections take priority.

## n1rwj-mst

No extension-specific changes for N1RWJ ICWC MST.

## n1rwj-ns

No extension-specific changes for N1RWJ NCCC Sprint CW.

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-randomgram

No extension-specific changes for N1RWJ RandomGram.

## n1rwj-rbn

- Removes the Station filter because newer HaLo kernels reject the custom
  provider calls. Saved station selections are ignored. Receiver, mode,
  CW speed, distance and My Signal settings are preserved.
- Native Spots rows show the reporting receiver and the CW speed when
  known.
- Adds an operator guide to the catalog and compatible install screens.
  Earlier settings and About screenshots remain in the repository's
  historical images.

## n1rwj-skcc

- The companion panel continues to show members heard in cached CW spots.
  Its instructions now point to the native Spots page for station selection.
- Adds an operator guide to the catalog and compatible install screens.

## n1rwj-sst

No extension-specific changes for N1RWJ K1USN SST.

## n1rwj-wrt

No extension-specific changes for N1RWJ Weekly RTTY Test.

## n1rwj-zombie

No extension-specific changes for Zombie Shuffle.

## Repository notes

- The installed-host verifier and RBN preview support Regular and Next
  kernel interfaces. The development guide documents hot reloading a
  workspace with the official tools.
- The retired CQ WW preview is excluded from this release. Use the
  official CQ WW extension for current operations.
