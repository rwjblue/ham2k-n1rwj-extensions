# v0.14.2 — Grouped extension settings

Zombie Shuffle combines its options and About guide in one dialog. Contest settings target Activities, and RBN settings move under Spotting. Existing preferences and Data Files access are preserved.

## n1rwj-bigfoot

No extension-specific changes for BIGFOOT Hunt.

## n1rwj-contest-calendar

No extension-specific changes for N1RWJ Contest Calendar.

## n1rwj-cwt

- On hosts with an Activities settings section, **CWT Prefill** opens as one dialog under **Settings → Activities**.
- Saved call-history sources and the Data Files shortcut remain available. Hosts without Activities keep the standalone settings entry.

## n1rwj-mst

- On hosts with an Activities settings section, **MST call history** opens as one dialog under **Settings → Activities**.
- Saved sources and the Data Files shortcut are preserved. Hosts without Activities keep the standalone settings entry.

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-randomgram

No extension-specific changes for N1RWJ RandomGram.

## n1rwj-rbn

- Open the existing RBN options from **Settings → Spotting → RBN**. Saved filters, reception preferences and export choices are preserved.
- Older hosts without settings grouping retain the standalone RBN entry.

## n1rwj-sst

- On hosts with an Activities settings section, **SST call history** opens as one dialog under **Settings → Activities**.
- Saved sources and the Data Files shortcut are preserved. Hosts without Activities keep the standalone settings entry.

## n1rwj-wrt

No extension-specific changes for N1RWJ Weekly RTTY Test.

## n1rwj-zombie

![Zombie Shuffle midnight radio club](https://github.com/rwjblue/ham2k-n1rwj-extensions/releases/download/v0.14.1/zombie-shuffle.png)

- One **Zombie Shuffle** dialog combines call-history options and the offline About guide, illustration, official rules and summary-sheet links.
- On hosts with an Activities settings section, open **Settings → Activities → Zombie Shuffle**. Hosts without that section keep one standalone settings entry.
- Saved source settings, cached history and the Data Files shortcut are preserved. The separate **Zombie Shuffle · About** entry is removed.

## Repository notes

- All ten extensions and shared workspaces retain synchronized versions and GitHub archives. Catalog submissions select only CWT, MST, SST, RBN and Zombie Shuffle; there are no universal dependency changes.
- The temporary CQ WW preview is retired and excluded from this release. Use the official `ham2k-cqww` extension; historical archives remain available.
- The CWT settings change is synchronized to [Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1). Other runtime changes affect their own extensions; repository guidance, navigation documentation and personal packaging are exempt from CWT synchronization.
- Current public host source supports Spotting grouping but has not yet registered Activities. The contest placement follows Sebastián's requested host section and preserves the SDK's older-host fallback.
- Lint, strict typechecks, 1,748 tests and official ES2020 builds/packages cover the ten extensions. Upstream CWT also passed 134 tests, typechecking, build and packaging. Native settings UI acceptance remains unverified.
