# v0.24.0 — Contest call history from Super Check History

CWT, MST, NCCC Sprint, SST, and WRT now download call history directly from Super Check History. WRT gains name and location suggestions. Native HaLo keeps its last successful download available offline.

## n1rwj-bigfoot

No extension-specific changes for BIGFOOT Hunt.

## n1rwj-bkg

No extension-specific changes for BKG Companion.

## n1rwj-cat-macros

No extension-specific changes for N1RWJ CAT Macros.

## n1rwj-contest-calendar

No extension-specific changes for N1RWJ Contest Calendar.

## n1rwj-cwt

- Download the CWOPS history file from Super Check History on desktop or mobile for name and exchange suggestions.
- Lookup notes show the date through which the source data is current, alongside the download date.

## n1rwj-mst

- Restore MST history refresh through Super Check History on desktop and mobile. Use the cached file for name and location suggestions. Enter the serial number copied for each contact.

## n1rwj-ns

- Use Super Check History’s shared NAQP CW file for name and location hints in NCCC Sprint. Refresh it on desktop or mobile and reuse the downloaded file offline.

## n1rwj-rbn

## n1rwj-skcc

No extension-specific changes for SKCC Companion.

## n1rwj-sst

- Refresh the K1USN SST file from Super Check History on desktop or mobile for name and state, province, or DX suggestions.

## n1rwj-wrt

- Download WRT history from Super Check History on desktop or mobile for name and location suggestions from the cached file. Enter the serial number copied for each contact.

## n1rwj-zombie

No extension-specific changes for N1RWJ Zombie Shuffle.

## Repository notes

The HaLo web app cannot refresh these five files because the provider restricts cross-origin requests.
