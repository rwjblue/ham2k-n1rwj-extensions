# v0.7.0 — Reliable reception scheduling and clearer report info

PSK Reporter and RBN now schedule reception work with host timers and offer
clearer Status and About views. Both reception extensions require a Ham2K
version supporting extension API 3. Contest extensions retain API 1.

## Shared changes

- Updated the shared build toolchain to Ham2K extension SDK 0.8.1 and
  extension tools 0.7.0. All seven extensions are rebuilt and republished;
  declared shared-library compatibility ranges are unchanged.

## n1rwj-cqww

No extension-specific changes for N1RWJ CQ WW (temporary).

## n1rwj-cwt

No extension-specific changes for N1RWJ CWT.

## n1rwj-mst

No extension-specific changes for N1RWJ ICWC MST.

## n1rwj-psk-reporter

- Requires a Ham2K version supporting extension API 3.
- Live connection deadlines, heartbeats, reconnects, and queued history requests
  now use host timers. Automatic history requests respect the shared cooldown
  without waiting for another render, while hidden views stop collecting.
- Dirty reports are saved in batches even after panels stop rendering, with
  bounded retries and protection against overlapping writes. Pending history
  cooldowns survive reloads conservatively.
- Report info now separates Status from About, with selected-band freshness,
  connection and history state, actionable warnings, and source and map guidance.
  Text wraps on small panels and with larger text settings; closing info restores
  the previous report page.

## n1rwj-rbn

- Requires a Ham2K version supporting extension API 3.
- Visible My Signal panels schedule automatic checks with host timers.
  Visibility expiry and app-hide handling pause automatic work; delayed storage
  cannot start a scheduled request after its view becomes inactive.
- HTTP 429 cooldowns remain shared between My Signal and RBN Spots, use real
  timer delays, and survive reloads conservatively.
- Report info now separates Status from About, distinguishes successful checks
  from selected-band report freshness, and explains refresh limits, data sources,
  and map origins. Warnings take priority, text wraps at larger sizes, and closing
  info restores the previous report page.

## n1rwj-sst

No extension-specific changes for N1RWJ K1USN SST.

## n1rwj-wrt

No extension-specific changes for N1RWJ Weekly RTTY Test.

## Repository notes

- Added reproducible reception-info mockups and installed-kernel timer probes.
- The private spot-filter bridge has a type-only compatibility adapter for the
  newer SDK; its runtime behavior is unchanged. The same adapter is pushed to
  [the upstream CWT PR](https://github.com/ham2k/extensions/pull/1).
- Reception runtime changes affect only PSK Reporter and RBN. Release versioning,
  packaging, and tooling are exempt from CWT/CQ WW behavior synchronization.
- Automated tests and installed-kernel probes do not establish native UI,
  background/foreground, or sleep/resume behavior; those app checks remain pending.
