# v0.7.3 — RBN spot fixes and PSK Reporter listener IDs

RBN keeps available spots through partial refresh failures, improves receiver
filtering, and keeps different stations on the same frequency selectable.
PSK Reporter retains reports from listener IDs, and CWT call-history filtering
now requires an explicit choice in RBN settings.

## n1rwj-cqww

No extension-specific changes for N1RWJ CQ WW (temporary).

## n1rwj-cwt

- CWT no longer requests automatic selection of its call-history spot filter.
  Download **CWops CWT call history**, then choose **CWT call-history file**
  under **Settings → RBN → Spots — Who I might hear → Call-history filter**
  to opt in. Existing saved RBN choices remain unchanged.
- This behavior is synchronized with the official extension in
  [Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1).

## n1rwj-mst

No extension-specific changes for N1RWJ ICWC MST.

## n1rwj-psk-reporter

- Retains reports from listener IDs such as `SWL`, `FWG`, `I0-1589`, and
  `US-E-015` in live updates, HTTP history, and saved caches. Valid reported
  grids place these receivers on the map; receivers without a usable grid
  remain in the list.
- **Who I hear** accepts an exact receiver ID in **Watch callsign or receiver ID**.
  **Who hears me** continues to require a transmitting callsign.

## n1rwj-rbn

- **All calls** is now the default and reset value for call-history filtering.
  Existing saved CWT, MST, and SST filter choices remain selected until you
  change or reset them.
- Incomplete refreshes retain successful receiver/band reports, successful
  first pages, and unexpired cached reports. Settings explain incomplete
  refreshes, and requests allow more time before timing out.
- Small receiver and geographic selections query receivers directly before
  report limits apply, improving coverage on busy bands. Bare receiver IDs
  use directory geography when all family nodes agree; conflicting grids
  are excluded from grid-region and distance filters.
- Explains Vail's omitted numeric skimmer suffixes. Saved choices such as
  `KM3T-2` stay strict and may return no reports; explicitly choose `KM3T`
  only when you intend to include the whole receiver family.
- Opening **Settings → RBN** shows service, database, connectivity, or offline
  warnings at the top while keeping settings editable.
- Different stations on the same frequency stay separately selectable through
  the [HALO-741](https://cabo.ham2k.com/halo/c/741) workaround. Portable suffixes
  are preserved, and repeated reports still collapse normally. The RBN callsign
  reference can remain in saved contacts selected from these spots.

## Repository notes

- All seven extensions and shared packages advance to 0.7.3. GitHub archives
  every bundle and checksum; only CWT, PSK Reporter, and RBN are selected for
  catalog publication. No root dependency or shared runtime update is included.
- CWT behavior is synchronized on the upstream `codex/cwt-call-history` source
  branch. RBN, PSK Reporter, and personal versioning/packaging changes do not
  affect upstream CWT or CQ WW behavior and are exempt from synchronization.
- All 947 tests across 73 files pass, along with lint, strict typechecks,
  ES2020 builds, official packaging, and release checksum validation.
  Live RBN comparisons matched the tested nearby-receiver CW station sets;
  raw report parity, digital website parity, and native UI verification of
  the new station references remain incomplete.
