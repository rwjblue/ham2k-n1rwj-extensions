# v0.7.4 — RBN reference icons and call-history refresh fixes

RBN references display the radar icon, including references already saved in
contacts. CWT, MST, and SST give N1MM call-history refreshes more time while
retaining the previous history when a refresh times out.

## n1rwj-cqww

No extension-specific changes for N1RWJ CQ WW (temporary).

## n1rwj-cwt

- N1MM call-history discovery and download share an eight-second refresh
  deadline, allowing slower responses without exceeding the host's conversion
  deadline. Timed-out or late responses preserve the previous cached history.
  Older hosts without timer support retain a bounded fallback.
- This behavior is synchronized with the official extension in
  [Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1).

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-rbn

- RBN station references use the radar icon instead of the red question-mark
  badge while the extension is enabled. Already-saved references are recognized
  without migration or deleting contact data.
- Adds one collapsed **RBN** chip in the logging panel's secondary controls
  for editing the contact's RBN references. You can hide the chip in
  logging-control settings without affecting the reference icons.
- Preserves full-callsign station references, portable suffixes, separate
  station selection in Spots, report deduplication, and export behavior.
  No contest exchange field or activity setup is added.

## Repository notes

- All seven extensions and shared packages advance to 0.7.4. GitHub archives
  every bundle and checksum; CWT, MST, SST, and RBN are selected for catalog
  publication. The shared downloader change is documented under each affected
  consumer; no universal dependency update is included.
- CWT behavior is synchronized on the upstream `codex/cwt-call-history` source
  branch. MST/SST-specific adapters, RBN, and personal versioning/packaging
  changes are exempt from CWT synchronization. CQ WW behavior is unchanged.
- Validation covers 965 tests across 74 files, lint, strict typechecks, ES2020
  builds, official packaging, and release checksums. RBN registration passes
  against the installed Next 26.9.0 build 177 JavaScript kernel under Node VM.
  Native UI rendering of the new RBN badge and chip has not been verified.
