# v0.9.0 — Contest Calendar and compact reception controls

Add an optional Contest Calendar panel for Home and other customizable layouts.
Compact reception controls leave more room for maps, and RBN exports one HTML
reception report by default.

## n1rwj-contest-calendar

- New optional panel shows active and upcoming contests, UTC or device-local
  times, mode filters, saved contests, and sponsor rules. Add it to Home or another
  customizable layout; it is available on every screen size and is never added
  automatically. Small panes open a native Browse form.
- Ham2K manages the attributed ContestClock catalog as a Data File containing
  thirty days of coverage, eligible for refresh after seven days. The pane previews
  fourteen UTC calendar days; Browse shows the full downloaded calendar. Native
  hosts retain successful downloads for offline replay, and invalid updates retain
  the last usable data. The panel labels old or insufficient coverage and updates
  event status without downloading data.
- Requires extension API 5 and native panel scenes. Calendar data is by Joe Leone,
  W4GGJ, under CC BY 4.0; sponsor schedules remain authoritative.

## n1rwj-psk-reporter

- Compact panes use outlined Band and Window menus that show the selected value
  while leaving more space for the reception map. Refresh, Details and Back use
  compact native controls, and status text wraps when needed. Wide panes keep
  their normal native controls.

## n1rwj-rbn

- Compact panes use outlined View, Band and Window menus that show the selected
  value while leaving more space for the reception map. Refresh, Details and Back
  use compact native controls, and status text wraps when needed. Wide panes keep
  their normal native controls.
- Exports select only the HTML reception report by default. Choose companion
  CSV, JSON, SVG map, or Markdown files under **Settings → RBN → Exports → Additional
  export files** when wanted.

## Repository notes

- All eight extensions and shared packages advance to 0.9.0, with unchanged
  dependencies and existing host compatibility ranges. Contest Calendar, RBN and
  PSK Reporter are selected for catalog submission; GitHub archives all eight
  bundles and their checksums.
- Validation passes 1,264 tests across 93 files, lint, strict runtime/test/task
  typechecks, eight ES2020 builds, official packaging and all eight bundle/checksum
  pairs. The installed-kernel compatibility probe passes against Ham2K Next
  26.9.0 build 177 for every extension.
- Calendar verification covers deterministic unit and bundled-sandbox behavior
  plus the installed JavaScript kernel probe. Native Calendar installation, UI,
  mobile, accessibility, production networking and lifecycle acceptance remain
  unverified. Compact reception controls have synthetic Flutter fixture coverage;
  installed-app and mobile acceptance remain pending.
- Calendar and reception-only behavior, plus personal release metadata, are
  exempt from CWT and CQ WW upstream synchronization. Contest behavior and
  historical release notes are unchanged.
