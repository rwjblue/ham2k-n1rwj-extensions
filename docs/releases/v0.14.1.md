## n1rwj-zombie

![Zombie Shuffle midnight radio club](https://github.com/rwjblue/ham2k-n1rwj-extensions/releases/download/v0.14.1/zombie-shuffle.png)

The [Zombie Shuffle](https://www.zianet.com/qrp/ZOMBIE/pg.html) is a relaxed Halloween CW gathering: October 30, 2026, 15:00–midnight local time, at 5 W or less on 80, 40, 20, 15 and 10 meters. Exchange RST, state/province/country, Zombie number and a spooky name. HI, AK and DX have flexible hours; confirm current details on the official page.

- The graveyard background now fills all four panel corners, matching BIGFOOT's existing fix.
- An event countdown shows time until the start, then time remaining, using your configured event-day UTC offset and flexible-hours setting. Scene and detailed watch refresh once per minute without rereading the log.
- When Zombie history has no location, untouched SPC can default from the host's callsign lookup: a known US/Canadian state or province, or a DX country. Corrections and deliberate clearing still win; ordinary directory names never become Zombie identities.
- The panel selector now has an original, offline illustration of the headphone-wearing Zombie and moonlit radio shack.
- **Zombie Shuffle · About** in extension settings includes the same offline illustration, a general event guide, official rules and summary-sheet links, and the [operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/tree/main/extensions/contests/n1rwj-zombie#readme).

Native app UI and on-air acceptance remain pending.

## Repository notes

All 11 extensions retain synchronized versions and GitHub archives; only Zombie has behavior changes for catalog publication. Zombie-only runtime and artwork changes, plus personal release packaging, are exempt from the temporary CWT/CQ WW upstream synchronization requirements. The installed-kernel check and browser preview do not establish native device or on-air acceptance.
