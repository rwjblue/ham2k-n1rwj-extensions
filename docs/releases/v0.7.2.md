# v0.7.2 — RBN startup fix and standard contest summaries

RBN loads receiver entries such as `UNKNOWN` without failing the startup
directory refresh. Contest extensions use the logger's standard score summaries,
and CQ WW suggests the nearest contest mode when setting up an operation.

## Shared changes

- Updated the Ham2K extension SDK from 0.8.1 to 0.9.0, including support for
  standard contest summaries. This root dependency update affects every bundle.

## n1rwj-cqww

- Uses the standard whole-contest title, score, QSO/point arithmetic, and band
  details, with localized zone, country, and RTTY state/province multiplier
  totals. Daily summaries are omitted; scoring rules and older saved checkpoints
  remain compatible.
- Ranks RTTY, SSB, and CW activity suggestions by their contest dates and defaults
  new operation setup to the nearest upcoming mode. Already configured operations
  keep their exchange settings.
- This personal extension remains temporary. Its behavior is synchronized with
  the official extension in [Ham2K/extensions PR #2](https://github.com/ham2k/extensions/pull/2).

## n1rwj-cwt

- Uses the standard session title, score, QSO/point arithmetic, and band details.
  Daily summaries are omitted; cross-band unique-call scoring and older saved
  checkpoints remain compatible.
- Behavior remains synchronized with the official extension in
  [Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1).

## n1rwj-mst

- Uses the standard session title, score, QSO/point arithmetic, and band details.
  Daily summaries are omitted; existing ICWC MST scoring rules are preserved.

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-rbn

- Fixed receiver-directory refresh failures at startup when RBN includes an
  entry such as `UNKNOWN`. Receiver IDs do not have to be amateur callsigns.
- Retains these receivers in My Signal, Spots, and saved caches, matching the
  supplied ID and using its grid for map positions and receiver filters.
  Receivers without a usable location can still appear in the report list.
- Skips malformed receiver IDs without discarding the rest of a valid directory;
  changed columns, conflicting entries, and unusable responses still retain the
  last good cache.

## n1rwj-sst

- Uses the standard session title, score, QSO/point arithmetic, and band details.
  Daily summaries are omitted; existing K1USN SST scoring rules are preserved.

## n1rwj-wrt

- Uses the standard session title, score, QSO/point arithmetic, and band details.
  Daily summaries are omitted; existing Weekly RTTY Test scoring rules are preserved.

## Repository notes

- All seven extensions and shared packages advance to 0.7.2. GitHub archives
  every bundle; the shared SDK update selects all seven for catalog publication.
- RBN behavior and personal release packaging are exempt from upstream CWT/CQ WW
  synchronization. Contest changes are synchronized with their respective PRs.
- Deterministic unit and sandbox bundle tests cover receiver parsing, locations,
  cache replay, and filters. Native HaLo build-177 startup verification remains
  outstanding.
