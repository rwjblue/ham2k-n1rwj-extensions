# v0.5.1 — Responsive reception panels and clearer maps

RBN and PSK Reporter keep cached reports visible and controls responsive while
network requests run. Their maps now use a clearer north-up fitted view and
preserve coastlines beneath the attribution text.

## n1rwj-cqww

No extension-specific changes for N1RWJ CQ WW (temporary).

## n1rwj-cwt

No extension-specific changes for N1RWJ CWT.

## n1rwj-mst

No extension-specific changes for N1RWJ ICWC MST.

## n1rwj-psk-reporter

- Force reload returns immediately while history loads, keeping cached and live
  reports visible. Repeated reloads share pending work, including queued requests.
- Pending history adds one-second render ticks. Completion returns to the normal
  five-second cadence used by MQTT heartbeats and subscription leases. These
  ticks do not start a new HTTP request every second; the automatic history
  cooldown remains five minutes.
- History requests use Polo's network timeout instead of the extension's
  seven-second limit. Details show host failures and request duration as an upper
  bound through the render that observes completion.
- The default fitted map uses a north-up projection, makes better use of short
  panels, keeps date-line clusters together, and prioritizes nearby country
  labels. The optional station-centered view retains distance rings.
- Coastlines continue beneath attribution instead of ending at an ocean-colored
  strip above the map's bottom edge.

## n1rwj-rbn

- My Signal starts due requests in the background and renders cached reports
  immediately. Manual refresh keeps panel controls available while HTTP runs.
- Pending requests add one-second render ticks to show completed results promptly,
  then restore the normal 60-second cadence. Panels and repeated refreshes share
  pending requests; these ticks do not fetch once per second.
- My Signal uses Polo's network timeout instead of the extension's three-second
  limit. Details show request duration as an upper bound through the render that
  observes completion. Cached results and retry timing handle longer requests and
  extension restarts.
- The default fitted map uses a north-up projection, makes better use of short
  panels, keeps date-line clusters together, and prioritizes nearby country
  labels. The optional station-centered view retains distance rings.
- Coastlines continue beneath attribution instead of ending at an ocean-colored
  strip above the map's bottom edge.

## n1rwj-sst

## Repository notes

- All six extensions and shared workspaces advance together to 0.5.1. Only RBN
  and PSK Reporter have behavior changes and are selected for catalog submission;
  GitHub archives every extension bundle and checksum.
- Validation: 671 automated tests, strict typechecks, lint, official ES2020 builds,
  and packaging checks. Static previews cover light/dark maps, distant reports,
  compact panels, and date-line clusters. Native Polo UI and lifecycle
  verification remains pending.
- The changed shared reception package has only RBN and PSK Reporter consumers.
  Contest runtime behavior is unchanged, so CWT/CQ WW upstream synchronization
  does not apply.
