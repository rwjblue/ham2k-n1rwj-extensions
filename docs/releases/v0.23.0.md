# v0.23.0 — CAT Macros

CAT Macros adds a dockable panel for your own radio commands. Run a saved macro from its button or an EXP KEYS shortcut.

## n1rwj-cat-macros

- Add **CAT Macros** to your layout. In **Settings → CAT Control → CAT Macros**, give each macro a button label, a shortcut alias, the target receiver, and its CAT command.
- Use plain text or HaLo Liquid templates for labels and commands. Choose **Text** for text-based protocols or **Hex bytes** for binary protocols such as Icom CI-V.
- Enable `EXP KEYS` and add `CATMACRO <alias>` in **Keyboard Shortcuts → Commands** to run a macro with a key combo.
- Requires HaLo extension API 23. The guide includes an IC-7300 noise blanker example and the available template fields. [CAT Macros operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/main/extensions/tools/n1rwj-cat-macros/README.md)
