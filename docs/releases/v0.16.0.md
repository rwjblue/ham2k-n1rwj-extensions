## n1rwj-bkg

**BKG Companion** helps members and prospective members find and work the Brass Knuckle Gang.

- Daily native Data Files downloads keep the public member roster available offline. Failed or invalid refreshes retain the last good roster.
- Additive Info notes show BKG membership on every band and mode while preserving callbook details, saved exchanges and operator corrections.
- An optional BKG panel shows your member card, recruits, recent member spots and operation progress. Identity follows the operation or active profile, without extra extension settings.
- Native **Worked the Gang** chasing counts distinct members worked on **2m CW**. Nonmembers can participate; stable member numbers preserve target identity across callsign changes.

Requires extension API 9. Hosts that gate native Chasing behind an experiment need **EXP CHASE**. Existing chase results may need an extension reload and EXP CHASE off/on on a device holding the complete log after roster changes. See the [operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/tree/main/extensions/activities/n1rwj-bkg#readme).

## n1rwj-zombie

Removes downloadable Zombie Shuffle call history because N1MM no longer lists the source file. Updating the extension removes the Zombie Data Files entry and its refresh error.

- Removes the source URL setting, downloader, file parser, snapshot cache and N1MM network grants. Previously downloaded snapshots are no longer used; no replacement roster is bundled.
- Keeps exchange suggestions from your logged Zombie contacts, including event-specific bonus filtering, portable callsign handling and leading zeros. Explicit corrections and deliberate clearing still win.
- Keeps the offline event guide under **Settings → Activities → Zombie Shuffle**, plus scoring, exports, the graveyard and rebirth watch.

Copy and confirm each station’s Zombie number and spooky name on the air. Ordinary directory names never become Zombie identities.
