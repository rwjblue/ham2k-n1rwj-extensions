# v0.7.5 — Reception filters and optional RBN minimum SNR

RBN My Signal can filter weak reports with an optional minimum SNR. RBN and
PSK Reporter also offer more report windows and an in-panel band menu for
filtering maps, receiver lists, and report details.

## n1rwj-cqww

No extension-specific changes for N1RWJ CQ WW (temporary).

## n1rwj-cwt

No extension-specific changes for N1RWJ CWT.

## n1rwj-mst

No extension-specific changes for N1RWJ ICWC MST.

## n1rwj-psk-reporter

- Adds 1, 3, 5, 10, and 45-minute report windows alongside 15, 30, and
  60 minutes. The default remains 15 minutes; live and recent-history
  reports honor the selected window.
- Tap the band label in the panel summary to filter the map, receiver list,
  and report details without opening settings. The selection belongs to
  that panel placement; the saved Band remains the restart default.

## n1rwj-rbn

- Adds **Minimum SNR (dB)** to My Signal's panel options. It is blank by
  default. Set a value to show only reports at or above that SNR on both
  the map and receiver list; clear it to show all reports again.
- The SNR filter uses each receiver's latest report per band and mode.
  Reports without SNR are hidden only while a minimum is set. Zero and
  negative thresholds are supported. The setting is saved per panel
  placement and shown in status and Details; RBN Spots and refresh timing
  remain unchanged.
- Adds 1, 3, 5, 10, and 45-minute report windows alongside 15, 30, and
  60 minutes. The default remains 15 minutes; short-window snapshots
  survive cache restoration.
- Tap the band label in the panel summary to filter the map, receiver list,
  and report details without opening settings. The selection belongs to
  that panel placement; the saved Band remains the restart default.
