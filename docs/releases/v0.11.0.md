# v0.11.0 — BIGFOOT Hunt and Zombie Shuffle

Adds independently installable extensions for the 2026 BIGFOOT Hunt special
event and Zombie Shuffle, with progress tracking, exchanges and exports.

## n1rwj-bigfoot

- Track the confirmed October 13–21, 2026 event with seven BIGFOOT letter slots,
  a separate W4S Skunk Ape bonus, and independent Mixed, CW, Phone and Digital
  progress. Add the optional BIGFOOT Hunt panel for a fuller breakdown.
- Fill the second O with a separate W7O contact that differs in band, normalized
  mode or UTC date. Progress follows logged corrections and deletions.
- Export eligible event contacts as ADIF or a CSV worksheet to help prepare the
  organizer's certificate request. Submission remains manual.

Requires extension API 1 and the declared shared libraries. Only the confirmed
2026 event profile is included. Unit, bundle and installed-kernel checks passed;
native UI and on-air acceptance remain unverified. See the
[operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.11.0/extensions/activities/n1rwj-bigfoot/README.md).

## n1rwj-zombie

- Log the October 30, 2026 CW event with native RST, state/province/country,
  a fixed Zombie number and a full spooky name. Leading zeros and each saved
  contact's sent exchange are preserved. Explicit corrections and clearing
  take precedence over suggestions.
- Check two-hour same-call, same-band rebirths and calculate the four scoring
  groups, including the combined 10m/15m group and 2026 bonus number `4321`.
- Refresh and cache the latest available N1MM Zombie call history, retaining
  the last successful download for offline use. Expired annual bonus numbers
  are omitted from suggestions without changing saved or copied exchanges.
- Export ADIF and a plain-text score summary for manual submission.

Requires extension API 1 and the declared shared libraries. Set the event's UTC
offset explicitly. Type `_` for spaces in names or countries, or paste multiword
text. Only the confirmed 2026 profile is included. The guide documents the
bonus-rebirth interpretation and unconfirmed 2026 submission deadline. Unit,
bundle and installed-kernel checks passed; native UI, multiword input and on-air
acceptance remain unverified. See the
[operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.11.0/extensions/contests/n1rwj-zombie/README.md).
