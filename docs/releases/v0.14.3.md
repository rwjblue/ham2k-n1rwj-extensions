# v0.14.3 — Automatic call-history sources

CWT, MST and SST discover their latest N1MM call-history files automatically. Their source URL settings pages are removed from Settings and Application Preferences; native data-file refresh and offline caches remain available.

## n1rwj-bigfoot

No extension-specific changes for BIGFOOT Hunt.

## n1rwj-contest-calendar

No extension-specific changes for N1RWJ Contest Calendar.

## n1rwj-cwt

- Removed the **CWT Prefill** source override settings page. The extension always discovers the latest CWOPS file from N1MM; earlier saved source overrides are ignored.
- Refresh **CWops CWT call history** under **Settings → Accounts, Services & Data Sources** (Data Files on older hosts). Offline caches, failed-refresh retention and exchange suggestions are preserved.
- Download-adapter errors now request an extension update instead of directing operators to a source override.

## n1rwj-mst

- Removed the **MST call history** source override settings page. The latest ICWC-MST file is discovered automatically; earlier saved source overrides are ignored.
- Native refresh remains under **Settings → Accounts, Services & Data Sources** (Data Files on older hosts). Cached offline names are preserved; received serials must still be copied on the air.
- Download-adapter errors now request an extension update instead of directing operators to a source override.

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-randomgram

No extension-specific changes for N1RWJ RandomGram.

## n1rwj-rbn

No extension-specific changes for N1RWJ RBN.

## n1rwj-sst

- Removed the **SST call history** source override settings page. The latest K1USNSST file is discovered automatically; earlier saved source overrides are ignored.
- Native refresh remains under **Settings → Accounts, Services & Data Sources** (Data Files on older hosts). Offline name and state/province/DX suggestions are preserved.
- Download-adapter errors now request an extension update instead of directing operators to a source override.

## n1rwj-wrt

No extension-specific changes for N1RWJ Weekly RTTY Test.

## n1rwj-zombie

- Shared N1MM download-adapter errors now request an extension update when the listing, download host or form changes. The previous valid call-history file remains available after a failed refresh.

## Repository notes

- All ten extensions and shared workspaces retain synchronized versions and GitHub archives. Catalog submissions select CWT, MST, SST and Zombie Shuffle; there are no universal dependency changes.
- The CWT behavior, translations, guide and downloader messages are synchronized to [Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1). MST/SST-only code, Zombie messages and personal packaging are exempt from CWT synchronization.
- Lint, strict typechecks, 1,751 tests and official ES2020 builds/packages cover the ten extensions. Upstream CWT passed 135 tests, root/workspace typechecking, official packaging and its focused bundle harness. Native settings UI acceptance remains unverified.
