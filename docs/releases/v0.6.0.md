# v0.6.0 — Weekly RTTY Test

Add an independently installable WRT extension with half-hour sessions,
name/QTH exchange suggestions, callsign multipliers, and ADIF/Cabrillo exports.
RBN spots now default to all supported modes while preserving saved choices.
All extension and shared-package versions advance together to 0.6.0.

## n1rwj-cqww

No extension-specific changes for N1RWJ CQ WW (temporary).

## n1rwj-cwt

No extension-specific changes for N1RWJ CWT.

## n1rwj-mst

- Updated the shared weekly-contest engine to configure timing, mode, bands,
  power classes, and multiplier rules independently. MST retains its existing
  one-hour CW sessions, serial/name exchange, and callsign multipliers.

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-rbn

- RBN spots now default to **All** supported modes: CW, RTTY, FT8, and FT4,
  allowing mode filtering on the native Spots page. Existing saved mode
  choices remain unchanged, and individual modes can still be selected in
  RBN settings.

## n1rwj-sst

- Updated the shared weekly-contest engine to configure timing, mode, bands,
  power classes, and multiplier rules independently. SST retains its existing
  one-hour CW sessions, state/province/DX exchange, and per-band multipliers.

## n1rwj-wrt

- Added Friday 0145–0215 UTC sessions on 80, 40, 20, 15, and 10m RTTY,
  with low-power and QRP setup.
- Added name and state/province/country-prefix exchange controls, with prior
  WRT contact and host lookup suggestions. Operator edits and clearing remain
  authoritative; foreign prefixes are preserved instead of replaced with DX.
- Score one point per eligible contact and one multiplier per unique callsign
  across the session, with per-band duplicate checks and session boundaries.
- Export name/QTH exchanges to ADIF and Cabrillo, including RTTY mode aliases
  and Cabrillo RY records without signal-report columns.
- Included an operator guide describing provisional scores, location edge
  cases, and export review. No downloadable call-history file, automatic score
  submission, or Hamscore streaming is included.

## Repository notes

- Full checks cover 698 tests across 57 files, strict typechecks, lint,
  ES2020 builds, and official packaging. WRT has 18 new deterministic tests;
  existing MST/SST regression coverage remains passing.
- Verified WRT activation and shared-library compatibility against the installed
  Ham2K 26.9.0 build 175 JavaScript kernel. Native UI and on-air testing remain
  pending; kernel verification runs under Node VM.
- WRT and its MST/SST engine changes do not affect CWT or CQ WW behavior.
  Neither temporary upstream PR requires synchronization for this work.
- External dependency versions and compatibility ranges are unchanged. The
  lockfile adds the WRT workspace and synchronizes repository versions.
