# v0.21.0 — Native reception maps

RBN My Signal and PSK Reporter now use HaLo’s built-in maps, with pan and zoom,
offline geography, and smaller extension downloads.

## Shared changes

- Updates the Ham2K extension SDK and build tools to 1.26.0.

## n1rwj-psk-reporter

- **Who hears me** and **Who I hear** use HaLo’s offline basemap. Pan and zoom
  while reports refresh, then use the map’s reset control to fit the latest
  reports.
- Requires HaLo extension API 25 or later. The catalog still offers compatible
  earlier versions to older hosts.

## n1rwj-randomgram

No extension-specific changes for N1RWJ RandomGram.

## n1rwj-rbn

- My Signal uses HaLo’s offline basemap for fitted reception maps and
  station-centered distance rings. Report updates preserve the current view.
- RBN still exports offline HTML reports with receiver tables, timelines,
  and contact context, plus Markdown, CSV, and JSON. This release retires
  embedded maps and the standalone SVG export. Other saved export choices
  still apply.
- Requires HaLo extension API 25 or later. The catalog still offers compatible
  earlier versions to older hosts.

## Repository notes

The signed HaLo macOS Next 26.11.0 build 195 contains the native map renderer.
An isolated Flutter and QuickJS harness used that build’s extension kernel
to verify maps, rings, and reception paths from synthetic reports.
[HaLo macOS Next download metadata](https://updates.ham2k.net/halo-next/macos-universal.json)
