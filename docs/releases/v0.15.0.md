## n1rwj-skcc

- **New SKCC Companion**, requiring extension API 9. Configure your exchange
  under Activities, download the official member roster in Data Files, and add
  an SKCC activity plus the companion panel to your operation.
- Offline names, member numbers, former calls and historical award dates;
  conservative lookup suggestions preserve operator corrections and clearing.
  Enable the SKCC members filter in RBN for native member spots, or use the
  companion’s age/speed-filtered list of possible C/T/S opportunities.
- Everyday SKCC, WES, SKS, SKSE, SKSA, Slow Speed Saunter, QSO Party, K3Y and
  Canadian Straight Key Month profiles. Record exchange/keying evidence, retain
  actual event operator identities, and export ADIF, worksheets and score reviews.
  Changing themes require review; SKS hides this extension’s assistance and
  reminds operators to close other assistance sources.
- Historical award audits cover C/T/S, WAS variants, DXC/DXQ, PFX, both QRP
  programs, Rag Chew, Marathon candidates, Triple Key, Monthly Brag, K3Y, CSKM
  and WAC. Complete-history ADIF analysis produces a dated saved summary and
  scoped CSV/text review worksheets, including exclusion reasons.
- Experimental native Chasing provides lifetime C/T/S, WAS, DX and QRP
  checklists. After refreshing the roster, reload the extension and rebuild
  EXP CHASE on a device holding the complete log. Calculated thresholds are
  not sponsor approval; special-event confirmation, Marathon confirmation and
  final application submission remain with SKCC.
- The companion reuses enabled spots sources and links to SKCC Sked; it does
  not republish the undocumented sked-status service. Read the
  [operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.15.0/extensions/activities/n1rwj-skcc/README.md)
  for setup, evidence requirements, scoring review and import/rescan limits.

## Repository notes

- All eleven extension bundles and checksums use synchronized version 0.15.0;
  only SKCC is selected for catalog submission. The new workspace and version
  bump do not update existing runtime dependencies.
- Bounded Vitest concurrency and a 15-second per-test timeout let existing
  sandbox/layout assertions finish on busy hosts; assertions are unchanged.
- Verification covers deterministic tests, official build/package validation,
  live roster parsing, and the installed build 183 JavaScript kernel with its
  actual ADIF exporter. Native UI, cross-device chasing rebuilds and on-air
  acceptance remain separate and unverified.
- SKCC, test-runner configuration and personal release packaging are exempt
  from temporary CWT upstream synchronization; CWT behavior is unchanged.
