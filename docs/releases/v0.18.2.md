## n1rwj-rbn

- Global controls appear directly under **Settings → Application Preferences →
  RBN**, grouped into exports, Spots, CW speed, receivers and distance settings.
- **About RBN** opens longer guidance and links in a separate read-only dialog.
  Service and filter warnings stay beside the controls. Saved settings and
  My Signal's per-panel options retain their existing behavior and scope.
- Catalog review request: following the Ham2K maintainer's guidance, use an
  inline preferences category for RBN. No sidebar entry or Common Preferences
  fields are requested.

## n1rwj-skcc

- Global controls appear directly under **Settings → Application Preferences →
  SKCC Companion**, grouped by exchange defaults, companion options, history,
  membership data and native chasing.
- **About SKCC Companion** opens operating guidance, history/chasing help and
  official links in a separate read-only dialog. Saved preferences, native
  Data Files management and operation-specific exchanges are preserved.
- Catalog review request: following the Ham2K maintainer's guidance, use an
  inline preferences category for SKCC Companion. No sidebar entry or Common
  Preferences fields are requested.

## n1rwj-zombie

- **Settings → Application Preferences → Zombie Shuffle** contains an explicit
  **About Zombie Shuffle** row. It opens the offline event guide, illustration,
  bonus-station list and official links in a separate read-only dialog.
- Exchange setup remains in the operation; display and motion options remain
  in each panel's tune settings. No new global settings are introduced.
- Catalog review request: following the Ham2K maintainer's guidance, use an
  inline preferences category for Zombie Shuffle. No sidebar entry or Common
  Preferences fields are requested.

## Repository notes

- All thirteen extensions and shared workspaces use the synchronized 0.18.2
  version. GitHub archives every bundle; catalog submission selects only RBN,
  SKCC Companion and Zombie Shuffle, skipping the ten unchanged extensions.
- Dependencies, shared runtime code and CWT behavior are unchanged. These
  independent settings changes and synchronized personal release packaging
  are exempt from upstream CWT synchronization.
- Local release validation passes lint, strict types, 1,951 tests in 150 files,
  all thirteen ES2020 builds and official packages, and all 26 release assets.
- Deterministic unit and ES2020 bundle checks are separate from live Ham2K UI
  testing; the new preferences layout has not been exercised in the native UI.
