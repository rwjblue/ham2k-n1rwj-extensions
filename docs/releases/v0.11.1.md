# v0.11.1 — BIGFOOT hunt spots

Identify BIGFOOT event stations, highlight contacts that add hunt credit,
and optionally limit RBN Spots to the event roster.

## n1rwj-bigfoot

- Mark the confirmed 2026 letter stations with a paw and W4S with a skunk.
  Station details identify the letter or bonus and explain W7O's two-contact
  rule. Annotations apply to BIGFOOT 2026 operations during the event.
- Highlight a spot when its band, actual mode, and UTC date would add Mixed,
  CW, or same-mode credit. The host labels this highlight **New Mult**.
  A qualifying second W7O is highlighted; a same-context repeat remains a
  duplicate. Completing Mixed on SSB preserves the independent CW hunt.
- Offer the bundled **BIGFOOT 2026** station filter to N1RWJ RBN. Install or
  update both extensions, then choose **Settings → RBN → Station filter →
  BIGFOOT 2026**. The list includes W7B, W7I, W7G, W7F, W7O, W7T, and W4S.

Compact markers identify targets; current needed status comes from live
scoring and the BIGFOOT panel. The roster includes worked and unworked targets
and requires no download. Requires extension API 1 and the declared shared
libraries. Automated and build-180 kernel checks passed; native UI and on-air
use remain unverified. See the
[operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.11.1/extensions/activities/n1rwj-bigfoot/README.md).

## n1rwj-rbn

- Rename **Call-history filter** to **Station filter** to include contest
  history files and fixed event rosters. **All calls** remains the default;
  existing explicit selections remain saved across operations and restarts.
- With BIGFOOT Hunt 0.11.1 enabled, choose **Settings → RBN → Station filter →
  BIGFOOT 2026** to limit native RBN Spots to the seven published event calls.
  Choose **CW** under **Spot mode** for a CW hunt. RBN does not supply SSB
  reports; use the organizer's spotting page for SSB.

The filter includes worked and unworked stations. Selection persists outside
the event and never switches automatically; choose **All calls** when finished.
An unavailable selected filter displays no spots until it is restored or
another filter is chosen. RBN requires extension API 5 and the declared shared
libraries. Native UI testing remains pending. See the
[operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.11.1/extensions/tools/n1rwj-rbn/README.md).
