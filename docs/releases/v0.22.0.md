# v0.22.0 — Contest CW presets and RBN SNR filter

SST, CWT, and MST now offer CW message sets for Run and Search & Pounce.
RBN Spots can filter CW reports by minimum signal-to-noise ratio.

## n1rwj-bigfoot

No extension-specific changes for BIGFOOT Hunt.

## n1rwj-bkg

No extension-specific changes for BKG Companion.

## n1rwj-contest-calendar

No extension-specific changes for N1RWJ Contest Calendar.

## n1rwj-cwt

- Choose **CWT CW** under **CW Keyer Messages → Message Set → Extensions → N1RWJ CWT**. The F1–F8 memories work with manual keying and Enter Sends Messages. The exchange uses the name and member number, QTH, or `CWA` from the operation setup.
- Requires HaLo Extension API 21 or later. The archive also includes `assets/CWT.h2kset` for manual import.

## n1rwj-mst

- Choose **MST CW** under **CW Keyer Messages → Message Set → Extensions → N1RWJ ICWC MST**. The F1–F8 memories work with manual keying and Enter Sends Messages. The exchange uses the live MST sent serial and your configured name.
- Requires HaLo Extension API 21 or later. The archive also includes `assets/MST.h2kset` for manual import.

## n1rwj-rbn

- Set **Minimum CW SNR (dB)** in RBN Spots to filter live cluster and Vail CW reports before Spots chooses one report per station, band, and mode. Reports with unknown SNR are hidden while a minimum is set.

## n1rwj-skcc

No extension-specific changes for SKCC Companion.

## n1rwj-sst

- Choose **SST CW** under **CW Keyer Messages → Message Set → Extensions → N1RWJ K1USN SST**. The F1–F8 memories work with manual keying and Enter Sends Messages. The exchange uses the name and location from the operation setup.
- Requires HaLo Extension API 21 or later. The archive also includes `assets/SST.h2kset` for manual import.
