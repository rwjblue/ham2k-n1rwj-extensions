# v0.13.1 — CAT-aware BIGFOOT tuning

The BIGFOOT forest now distinguishes connected CAT control from manual operation before offering Tune.

## n1rwj-bigfoot

- Show **Tune** only when the selected logging radio has a fresh, usable CAT connection and can accept a tuning request. Show **Connecting…** while it connects and **Manual tuning** when disconnected, unavailable, stale, or transmitting.
- Keep the spotted callsign and frequency visible. Letter/bonus selections remain useful for manual operation without sending radio commands. Connected tuning still rechecks the radio immediately before requesting a change.
- Refresh CAT availability every five seconds while the forest displays a fresh station lead. These checks reuse the held log and spots; the host pauses them while hidden. Existing API 7 and radio-write permission requirements are unchanged.
