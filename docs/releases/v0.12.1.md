# v0.12.1 — A warmer welcome to the BIGFOOT forest

BIGFOOT Hunt brings its forest personality to catalog discovery and the
**Add a Panel** picker, with a friendly description and an offline illustration
you can enlarge before adding the panel.

Native picker component preview with fixed decorative artwork:

![BIGFOOT Hunt forest preview in the native panel picker](https://github.com/rwjblue/ham2k-n1rwj-extensions/releases/download/v0.12.1/bigfoot-panel-preview-native.png)

## n1rwj-bigfoot

🌲🐾 **Meet your BIGFOOT trail before you add it.**

- 🌲 Catalog discovery now introduces the animated forest, CW/Mixed letter
  hunt, and 🦨 Skunk Ape bonus. Added search keywords include National
  Sasquatch Day, forest, letter hunt, and 2026.
- 🖼️ **Add a Panel** shows an offline **640 × 640** forest illustration with
  Bigfoot, the Skunk Ape, and seven letter tiles. Tap the thumbnail to enlarge
  it. Every tile uses the same decorative treatment; the picture displays no
  logged credit.
- 🧭 To start a new pane, open a **BIGFOOT Hunt 2026** operation and choose
  **Edit Layout → Add a Panel → BIGFOOT Hunt**. Leave the added panel visible
  while logging to see earned letters and celebrations. Existing Hunt panels
  keep their placement and settings.

This patch changes discovery presentation. CW and Mixed progress remain
independent, W4S remains a separate bonus, and the second W7O still requires
a different band, actual mode, or UTC date. On CW, use another band or UTC
date. Event rules, exports, and the existing hunt panel identity are unchanged.

Native picker component and installed build-180 JavaScript kernel checks
passed; the installed logger workflow and on-air use remain unverified.
See the [operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.12.1/extensions/activities/n1rwj-bigfoot/README.md).

## Repository notes

- All 11 extension bundles and their SHA-256 files use synchronized version
  0.12.1. Only BIGFOOT Hunt is selected for catalog submission. Dependencies,
  shared runtime code, and the private spot-filter protocol are unchanged;
  synchronized version bumps alone do not select the other catalog entries.
- Validation covers lint, strict typechecks, **1,604 tests across 118 files**,
  and all 11 official ES2020 builds and packages. The real native panel-picker
  component was tested with the bundled illustration, including thumbnail
  enlargement. The installed **Ham2K Mac Logger (Next) 26.9.0 build 180**
  JavaScript kernel accepts the extension. Component and kernel checks are
  separate from installed-logger UI and on-air acceptance.
- `mise run bigfoot:preview` now also exports the static picker artwork as
  `dist/bigfoot-scene-preview-panel.svg`, alongside the browser preview and
  companion scene JSON. The preview task uses synthetic data without accessing
  your logger or radio.
- BIGFOOT discovery presentation and personal packaging changes do not affect
  CWT or CQ WW behavior, so no upstream synchronization is required. See the
  [verification record](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.12.1/docs/VERIFICATION.md).
