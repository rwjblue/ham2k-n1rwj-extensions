## n1rwj-randomgram

- Import organizer-issued five-character TX groups from a complete message or
  a plain list, with owner, event, count and alphabet validation. Literal zeros
  and letters are preserved.
- Add the **RandomGram Exchange** panel for a large TX/RX readout and separate
  RST. Select a list position, apply explicit corrections and retain the exact
  sent group when editing saved contacts. Repeat same-band contacts are allowed.
- Use `RGSWL` for listening-only groups and `RGSKIP` for groups sent without a
  contact. Submission text includes unique valid received groups; ADIF exports
  preserve literal sent and received exchanges. `RGREPORT` provides copyable
  submission text and remains open while you copy it.
- Use the supplied guarded Liquid keyer template to send RST and the displayed
  group. Cut-number substitutions apply only to RST. Invalid or exhausted
  selections render an empty message.

Requires Ham2K extension API 5. Use one contact at a time on one device, and
manually select the next unused TX item after `RGSKIP`. Avoid comma-list batch
logging. Host exchange warning badges can lag behind edits until callsign or
focus changes refresh them. Mobile layout, actual CW transmission and
multi-device recovery remain unverified.

A synthetic native Mac session in Ham2K Power Logger (Next) 26.9.0 build 179
verified import, the panel, logging and edits, listening notes, exports and
keyer message rendering. See the
[operator guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.10.0/extensions/contests/n1rwj-randomgram/README.md)
for setup, commands, keyer installation and operating limits.

## Repository notes

- All nine extension bundles and their SHA-256 files are archived at the
  synchronized version. Only RandomGram has behavior changes and is selected
  for catalog submission; catalog review is separate from GitHub availability.
- Verification includes lint, strict typechecks, 1,415 tests, official ES2020
  builds and package validation. RandomGram has 151 deterministic tests.
- The native session used synthetic groups and contacts without transmitting
  CW. The report stayed open for 136 seconds and closed cleanly after its
  command timeout fix. See the
  [verification record](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.10.0/docs/VERIFICATION.md).
- RandomGram and synchronized release packaging do not change CWT or CQ WW
  behavior, so their temporary upstream PRs require no synchronization.
